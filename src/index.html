04

AI 활용과 검증

AI를 활용하고
결과는 직접 확인합니다

Codex · Claude

요구사항과 설계 초안은 직접 정리합니다. Codex와 Claude로 코드를 작성하고 더 나은 방법이나 놓친 문제를 검토합니다. 두 도구의 의견을 비교한 뒤 실제 코드와 테스트 결과를 확인해 반영합니다.

  1. 정의

    요구사항과 설계 기준 정리

    필요한 기능과 처리 규칙을 정합니다. 개발 순서와 테스트 기준도 직접 결정합니다.

  2. 탐색

    코드 작성과 개선안 검토

    AI로 코드와 테스트를 작성하고 설계 대안을 비교합니다. 서로 다른 도구로 같은 코드를 검토하고 로그를 분석하는 데도 활용합니다.

  3. 검증

    테스트와 실행 결과 확인

    API 명세와 기존 기능에 미치는 영향을 확인합니다. 실패하는 상황이나 한계값을 넣어 테스트하고 동시 요청과 실제 실행 환경도 살펴봅니다.

검증 사례

이미지 처리 코드는 힙을 384MiB로 제한한 JVM에서 테스트했습니다.큰 JPEG와 투명 PNG가 처리되는지 확인하고 축소한 이미지가 다시 커지지 않는지 검사했습니다. 서버 전체 부하를 재현한 시험과는 구분했습니다.
