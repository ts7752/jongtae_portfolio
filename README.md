# 이종태 포트폴리오

개발자 이종태의 프로젝트와 문제 해결 경험을 소개하는 정적 웹사이트입니다. 먹색·파랑·흰색 디자인에 데스크톱 고정 목차와 모바일 상단 메뉴를 사용합니다. 메인에서 담당 범위를 소개하고 상세 페이지에서 문제와 처리 방법 및 확인한 결과를 설명합니다. 정적 HTML·CSS와 Node.js 표준 라이브러리만 사용하며 별도의 DB나 인증 서버는 필요하지 않습니다.

## 사이트와 소스

- 사이트: https://ts7752.github.io/jongtae_portfolio/
- 소스: https://github.com/ts7752/jongtae_portfolio
- 메인과 DB·거래·백업·권한·자원·발송·프로젝트 상세 14개를 제공합니다.
- 회사 원본 코드·인수인계서·계정 정보·내부 근거 문서는 포함하지 않습니다.

## 로컬 실행

```sh
npm test
npm run build
npm run dev
```

로컬 주소는 `http://127.0.0.1:8765/`입니다. 다른 포트는 `PORT=8766 npm run dev`로 실행합니다. 개발 서버는 빌드 산출물만 제공하며 파일 수정 후 다시 빌드하고 브라우저를 새로고침합니다. 서버 자동 재시작·외부 호스팅을 뜻하지 않습니다.

Node.js 24를 사용합니다. npm 외부 의존성이 없어 설치 과정은 필요하지 않습니다. 로컬 빌드는 noindex이며 공개 빌드와 구분합니다.

```sh
npm test
npm run build:production
npm run check
```

공개 빌드에는 canonical·Open Graph·JSON-LD·sitemap을 생성합니다. 메인·상세 페이지는 JavaScript가 꺼져 있어도 읽을 수 있습니다. 404는 색인 대상에서 제외합니다. GitHub 프로젝트 하위 경로를 기본 주소로 사용하며 자체 도메인을 연결한 경우 `src/site.mjs`의 주소도 변경합니다.

## 구조

- `src/index.html`: 메인 페이지입니다.
- `src/stories.mjs`: 기존 DB·결제·백업·정책·업무·권한·UX 원고입니다.
- `src/additions.mjs`: 이미지 메모리·해외 발송 안전·알림·기동 보완 원고입니다.
- `src/projects.mjs`: 자라마켓·에너지 모니터링·기업 웹 상세입니다.
- `src/site.mjs`: 공개 주소와 작성자 정보를 관리합니다.
- `src/assets/`: 파비콘·1200×630 공유 이미지입니다.
- `src/*.css`: 승인된 디자인과 반응형 상세 페이지 스타일입니다.
- `scripts/build.mjs`: 정적 상세 페이지와 실제 링크를 생성합니다.
- `scripts/serve.mjs`: 로컬 전용 미리보기 서버입니다.
- `test/site.test.mjs`: 링크·페이지 구조·민감정보 패턴·검증 범위 회귀입니다.
- `scripts/check-publication.mjs`: 배포 파일과 소스의 민감정보 패턴·잘못된 파일 유형을 검사합니다.
- `.github/workflows/pages.yml`: PR 검사와 main 자동 Pages 배포입니다.
- `dist/`: 빌드 산출물이며 Git에서는 제외합니다.

## 업데이트와 배포

PR에서는 검사·공개 빌드만 수행하고 배포하지 않습니다. `main`에 반영되면 테스트 → 공개 빌드 → 공개 경계 검사 → dist 업로드 → GitHub Pages 배포가 실행됩니다. 배포에만 Pages 쓰기·OIDC 권한을 부여하고 외부 Actions는 커밋 SHA로 고정했습니다. 빌드 산출물만 배포하며 저장소 전체를 업로드하지 않습니다.

문구는 `src`에서 수정하고 위 검사를 실행한 뒤 커밋·푸시합니다. 배포 실패 시 Actions의 실패 단계를 확인하고 수정합니다. 이전 버전으로 되돌릴 때는 해당 변경을 revert하여 다시 검사·배포합니다. 강제 push나 환경 권한 완화로 실패를 우회하지 않습니다.

기본 URL은 GitHub Pages 주소이며 개인 도메인 구매·DNS 변경은 포함하지 않습니다. 검색 도구 소유 확인·사이트맵 제출·실제 색인 결과는 별도입니다. 하위 경로의 robots.txt는 도메인 루트 robots 정책을 대체하지 않습니다. 확인되지 않은 공개 Notion 주소는 연결하지 않습니다.

프로젝트 기간은 2026년 11월까지 확인한 작업 기록 기준이며 별도의 정확한 퇴사일을 추정하지 않습니다. 기존 목업·개인 근거집·회사 저장소는 이 사이트와 분리해 보존합니다.

인수인계서·원본 로그·회사 소스·인증값·개인 근거 문서를 빌드 디렉터리에 복사하지 않습니다. 검사는 고정 패턴을 확인하는 보조 장치이며 비밀정보 전수 탐지를 보장하지 않습니다.
